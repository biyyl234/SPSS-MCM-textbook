## 📖 教材结构

每个算法都包含 **六大模块**，结构清晰、一目了然：

!!! note "一句话讲清"
    用大白话告诉你这个算法是干啥的，30秒搞懂用途

!!! info "美赛适用场景"
    什么题型、什么问题用它，拿到题目就能对号入座

!!! abstract "通俗原理"
    生活类比 + 公式文字说明，大一学生也能看懂

!!! tip "SPSS操作步骤"
    具体到点哪个菜单、选什么变量、参数怎么填

!!! success "结果怎么看"
    输出表格中每个关键指标什么意思、怎么判断好坏

!!! warning "注意事项 & 决策指引"
    什么时候用、什么时候不用、常见坑、相似算法区别

## 🚀 学习路径建议

!!! tip "新手推荐路线"
    1. **第1章 描述性统计** — 拿到数据第一步，学会看数据
    2. **第3章 差异比较** — T检验/卡方/方差，组间比较必备
    3. **第4章 回归分析** — 建模核心，线性+逻辑回归
    4. **第8章 综合评价** — AHP/熵值法/TOPSIS，评价类题目神器
    5. **第6章 时间序列** — ARIMA，预测类题目常用
    6. **第11章 机器学习** — 随机森林/SVM，大数据题加分项
    7. **附录B 论文拆解** — 看获奖论文怎么组合模型
