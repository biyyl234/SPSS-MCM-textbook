    📐 功效分析¶

    本章导览

    这个分类是干什么的？

    功效分析回答的是一个研究设计阶段的问题：样本量到底够不够大？它在你正式收集数据之前就算清楚：要想以足够把握检出某个真实差异，需要招多少样本；反过来，现有样本量下，你有多大把握能发现效应。它不做假设检验，而是告诉你"实验要花多少钱、招多少人才不至于白做"。

    美赛什么题型常用？

    功效分析在美赛中很少直接作为解题模型，但它在两个地方很加分： - 题目要求你评估数据收集方案、说明样本量是否充足时，功效分析是最规范的论据。 - 论文中论证"我们采集的数据量足以支撑后续检验"时，引用功效分析结果能体现严谨性。 如果你拿到的是现成大数据集，基本用不到本章；只有涉及"规划抽样规模"时才用。

    学习路径建议

    先学功效分析之均值差（明星算法，最经典，讲透"样本量、功效、效应量、显著性水平"四者关系），再了解功效分析之线性回归。进阶部分按检验对象区分：相关性、率差、方差（多组比较）、广义模型（处理二项/计数结局），原理相通，只是背后的分布不同。

    基础级算法¶

    ⭐ 功效分析之均值差 基础级¶

    一句话讲清

    功效分析之均值差，就是在做两（或多）组均值比较之前，先算清楚：要检出预设的均值差异，每组需要多少样本，或者现有样本能达到多大的"检出把握"。

    美赛适用场景

    • 规划对照试验、问卷调查时，确定需要招募多少样本
    • 美赛中论证"现有数据量是否足以检出组间差异"
    • 评估已有预试验数据的功效够不够

    通俗原理

    功效分析绕着四个互相牵制的量转：

    • 显著性水平\(\alpha\)：容忍"误报"的概率，通常0.05。
    • 功效\(1-\beta\)：真实差异存在时，能成功检出它的概率，通常目标0.8。
    • 效应量\(d\)（Cohen's d）：均值差除以合并标准差：
    \[ d = \frac{|\mu_1 - \mu_2|}{\sigma_{pooled}} \]

    \(d\approx0.2\)小、\(0.5\)中、\(0.8\)大。效应越小，越难检出，需要样本越多。 - 样本量\(n\)：其他三个量定了，就能反解\(n\)。两独立样本双侧检验的近似样本量公式为：

    \[ n = \frac{2(z_{1-\alpha/2} + z_{1-\beta})^2}{d^2} \]

    其中 \(z_{1-\alpha/2}\) 为标准正态分布上 \(\alpha/2\) 分位数，\(z_{1-\beta}\) 为功效对应的分位数。

    生活类比：功效就像捕鱼。网眼大小（\(\alpha\)）、鱼到底多大（效应量）决定了要撒多大面积的网（样本量）才能有80%把握捕到这条鱼。鱼越小（效应小），网要撒得越大。

    注意：功效是"长期检出概率"，不是"这次一定显著"——达到80%功效也意味着仍有20%的可能检不出。

    SPSS [Statistical Package for the Social Sciences, 统计产品与服务解决方案]操作步骤

    1. 工具箱选"功效分析之均值差"
    2. 检验类型选两独立样本（也支持配对、单样本、单因素方差分析）；检验方向双侧
    3. 求解目标选样本量；\(\alpha=0.05\)，目标功效\(0.80\)，两组分配比ratio\(=1\)
    4. 效应量选数据估计优先（用预试验数据自动算Cohen's d，没有时手动给值）
    5. 运行后把结果向上取整，再用取整规模反算实际功效
    6. 看灵敏度分析：效应量上下浮动25%时样本量怎么变

    默认参数参考：两独立样本、双侧、\(\alpha=0.05\)、目标功效0.8、1:1分配，效应量由数据估计。

    结果怎么看

    以"新旧客服话术对比"案例为例（预试验每组75人）：

    • 效应量：\(d=0.33\)（小到中等效应）。
    • 核心结论：在双侧\(\alpha=0.05\)、目标功效0.8下，每组约需147例（两组共294例）才能较有把握检出该均值差。
    • 现有数据功效：按预试验每组75例，实际功效仅约0.516，明显低于目标——说明试点规模只够粗估效应量，正式研究要按294例规划。
    • 灵敏度：效应量下调25%（\(d=0.247\)）需260例/组；上调25%（\(d=0.411\)）只需94例/组。效应量估得越小、要的样本越多。

    怎么看：报告"达到80%功效每组需\(n\)例"；若担心试点高估了效应，建议按保守值（下调25%）招募。

    注意事项 & 决策指引

    什么时候用？设计两/多组均值比较的研究前，定样本量。

    什么时候不用？已经收集完数据、做假设检验时不需要功效分析（那是第3章的事）；现成大数据集通常样本量已远超需求。

    常见坑 - 坑1：把"达到目标功效"理解成"必然显著"。功效是概率，仍有漏检可能。 - 坑2：效应量拍脑袋给大了，导致样本量算得偏小、实际检不出。务必用预试验或文献估计效应量，并做灵敏度分析。 - 坑3：忽略前提。功效公式近似要求数据近似正态、方差齐，案例中已用Shapiro与Levene检验确认。

    和相似算法的区别 - vs 第3章t检验/ANOVA [Analysis of Variance, 方差分析]：t检验是拿到数据后检验差异是否存在；功效分析是之前算要多少样本。 - vs 功效分析之方差：均值差针对两组；方差（ANOVA）功效针对三组及以上。

    📐 功效分析之线性回归 基础级¶

    一句话讲清

    功效分析之线性回归，回答的是：要想让回归模型（或某个自变量的贡献）在统计上站得住，正式研究需要收集多少条样本。

    美赛适用场景

    • 规划问卷调研：已知大概的\(R^2\)，算需要多少份有效问卷
    • 论证回归分析的样本量是否充足

    通俗原理

    回归功效基于非中心\(F\)分布：

    • 先用预试验数据拟合OLS [Ordinary Least Squares, 普通最小二乘法]，得到调整\(R^2\)，换算成效应量：
    \[ f^2 = \frac{R^2}{1 - R^2} \]
    • 非中心参数 \(\lambda = n \cdot f^2\)，自由度 \(v = n - k - 1\)（\(k\)为预测变量数）。
    • 功效 \(= 1 - F_{nc}(F_{crit}; u, v, \lambda)\)，再二分反推满足目标功效的最小 \(n\)。
    • Cohen基准：\(f^2\approx0.02\)小、\(0.15\)中、\(0.35\)大。

    SPSS操作步骤

    1. 工具箱选"功效分析之线性回归"
    2. 指定目标列与预测变量列；效应来源选data_observed（用数据估计\(R^2\)）
    3. 分析模式选sample_size（求样本量）；\(\alpha=0.05\)，目标功效0.80
    4. 运行，查看所需最小样本量与功效曲线

    默认参数参考：\(\alpha=0.05\)、目标功效0.8，效应量由观测数据估计（用调整\(R^2\)，更保守）。

    结果怎么看

    以"顾客复购意愿"案例为例（4个预测变量，预试验150条）：

    • 观测\(R^2=0.183\)，调整\(R^2=0.161\)，换算 \(f^2=0.191\)（中等效应）。
    • 核心结论：\(\alpha=0.05\)、功效0.8下，正式研究至少需68条有效样本，此时功效80.5%。
    • 现有150条样本对应功效约99.5%，绰绰有余。

    怎么看：报告"至少需\(n\)条有效样本"；\(n\)对\(\alpha\)和目标功效敏感，收紧要求会明显增加样本量。

    注意事项 & 决策指引

    什么时候用？规划回归类调研、论证问卷样本量。

    常见坑 - 坑1：用未调整的\(R^2\)算效应量，会高估、样本量算少。应使用调整\(R^2\)。 - 坑2：忽略预测变量个数\(k\)。变量越多，自由度损失越大，需要样本越多。

    和相似算法的区别：本算法针对回归模型的整体或某个自变量的检验；均值差功效针对两组均值比较。

    进阶级算法速览¶

    📐 功效分析之相关性 进阶级¶

    进阶算法速览

    一句话：要检验两个连续变量的相关是否显著（\(H_0:\rho=0\)），需要多少对成对观测，或现有样本能检出多强的相关。

    美赛场景区：规划需要配对观测的相关分析（如培训学时与满意度），论证样本是否足够检出目标相关。

    核心原理：检验统计量与Fisher z变换为：

    \[ t = r\sqrt{\frac{n-2}{1-r^2}}, \quad z_r = \frac{1}{2}\ln\frac{1+r}{1-r} \]

    原假设下服从 \(t(n-2)\)，备择下按非中心参数 \(\delta = \rho\sqrt{n/(1-\rho^2)}\) 的非中心 \(t\) 分布精确算功效。近似样本量公式为 \(n = \frac{(z_{1-\alpha/2} + z_{1-\beta})^2}{z_r^2} + 3\)。

    操作要点：工具箱选"功效分析之相关性"；选x、y两列；相关类型pearson；求解目标sample_size；双侧检验。

    结果关键：案例（培训学时vs满意度）观测\(r=0.357\)，达80%功效至少需约56对；现有150对功效约99.6%。三问：现样本功效多大？需多少对？现规模能检出多小的\(|r|\)？

    注意：效应量越小、目标功效越高，所需对数越多。

    📐 功效分析之率差 进阶级¶

    进阶算法速览

    一句话：两组合格率/发生率比较（二分类结局），在给定两组率的前提下，需要多少样本才能检出这个率差。

    美赛场景区：规划临床试验、政策达标率对比，如降压治疗后达标率从30%提到50%需要多少患者。

    核心原理：对两组率 \(p_1, p_2\) 做反正弦变换得到效应量Cohen's \(h\)：

    \[ h = 2\arcsin\sqrt{p_1} - 2\arcsin\sqrt{p_2} \]

    按两率 \(z\) 检验的解析功效公式求每组样本量；向上取整后回代实际功效，并用蒙特卡洛模拟复核正态近似。

    操作要点：工具箱选"功效分析之率差"；填对照组率\(p_1\)、试验组率\(p_2\)；求解目标样本量；\(\alpha=0.05\)、双侧、1:1分配。

    结果关键：案例\(p_1=0.30\)、\(p_2=0.50\)，\(\alpha=0.05\)、功效0.8下共需186例（每组93）；蒙特卡洛经验功效0.798与解析0.801吻合。

    注意：样本量对\(p_1,p_2\)假设很敏感——率越接近50%、两组差越小，需要的样本越多。务必做\(p_1\)扰动敏感性分析。

    📐 功效分析之方差 进阶级¶

    进阶算法速览

    一句话：单因素方差分析（三组及以上均值比较）前，规划每组需要多少样本才能检出组间差异。

    美赛场景区：如比较三套策略、三套方案的效果，预试验后规划正式对比实验的样本量。

    核心原理：四要素互相牵制——效应量 \(f\)（由预试验 \(\eta^2\) 估计）、总样本量 \(N\)、\(\alpha\)、功效 \(1-\beta\)。效应量定义为：

    \[ f = \sqrt{\frac{\sum_{i=1}^{k} (\mu_i - \bar{\mu})^2 / k}{\sigma^2}}, \quad \lambda = N f^2 \]

    其中 \(k\) 为组数，\(\mu_i\) 为第 \(i\) 组均值，\(\sigma^2\) 为组内方差，\(\lambda\) 为非中心参数。\(f\approx0.1\) 小、\(0.25\) 中、\(0.4\) 大。基于非中心 \(F\) 分布按均衡分配反推每组样本量，取整后重算实际功效。

    操作要点：工具箱选"功效分析之方差"；填组数\(k\)；效应来源数据估计；求解目标所需样本量；\(\alpha\)与目标功效默认0.05/0.8。

    结果关键：案例（三套拣货策略，\(k=3\)）预试验得\(\eta^2=0.083\)、\(f\approx0.30\)（中效应），需每组37例、共111例，取整后功效约0.80。

    注意：需先做正态性与方差齐性（Levene）检验；若异方差严重，当前结论不适用，应改用Welch方差分析的模拟功效。

    📐 功效分析之广义模型 进阶级¶

    进阶算法速览

    一句话：当结局不是正态连续变量，而是二分类、计数等更复杂的结局时，用广义线性模型的功效分析来定样本量。是均值差功效的"升级版"。

    美赛场景区：规划安全性/不良反应对照研究——如联合用药使肝功能异常率从20%升到40%（\(OR [Odds Ratio, 比值比]=2\)），需要多少患者。

    核心原理：先按结局选分布族与链接函数（二项/泊松/负二项）；给定效应量、基线率、\(\alpha\)、分配比，用Wald检验的渐近功效二分求解总样本量。Wald检验统计量为：

    \[ z = \frac{\hat{\beta}}{SE(\hat{\beta})} \sim N(0, 1) \quad \text{under } H_0 \]

    再固定种子生成数据、拟合对应GLM [Generalized Linear Model, 广义线性模型]做蒙特卡洛模拟，在解点和1.25倍样本点核对解析近似是否靠谱。

    操作要点：工具箱选"功效分析之广义模型"；family选binomial；solve选n；填效应（OR=2）、基线率、\(\alpha=0.05\)、双侧、功效0.8；指定group与outcome列。

    结果关键：案例（二项结局、\(OR=2\)、基线20%）需总样本352例（对照176、暴露176）；蒙特卡洛实测功效81.1%，与解析80.1%吻合。

    注意：这是功效分析里最灵活但也最复杂的一类。结果对\(\alpha\)、基线率假设敏感；资源有限时可评估放宽\(\alpha\)或用单侧检验以降样本量。美赛中用到时，重点是把"样本量怎么来的"讲清楚。
